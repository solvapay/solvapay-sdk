First release of `solvapay`, the Python SDK, at 0.1.0: an API client generated from the committed spec, the paywall, webhooks, paid MCP tools (`solvapay[mcp]`) and agent payments (`solvapay[agents]`). It has its own version line, separate from the TypeScript packages, and passes the conformance suite pinned in `python/conformance.lock`.
