## Prerequisites

- Node.js 20+
- pnpm
- SolvaPay account (for real-backend examples)
- Supabase project (for Supabase examples)

From workspace root:

```bash
pnpm install
pnpm build:packages
```

## Run any example

```bash
cd examples/typescript/<example-name>
cp .env.example .env
pnpm dev
```

Two examples ship the template as `env.example` (no leading dot): `checkout-demo` and
`hosted-checkout-demo`. Each example's README names the target filename it loads —
some read `.env`, others `.env.local`. `express-basic`, `supabase-edge`, and
`supabase-edge-mcp-proxy` need no env file at all.

## Example notes

### express-basic

- Good first project for `payable.http()`
- Runs keyless: injects an explicit stub `apiClient` from `examples/typescript/shared`, so no secret key or backend is needed
- Header-based customer identity via `x-customer-ref`
- README: [examples/typescript/express-basic/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/express-basic/README.md)

### express-provider-linkage

- Provider-owned client + IdP: backend calls `ensureCustomer(externalRef)` before metering
- Simulates post-CLI-login requests with `x-provider-user-id`
- README: [examples/typescript/express-provider-linkage/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/express-provider-linkage/README.md)

### nextjs-auth0

- Auth0 Regular Web App + embedded Pay As You Go checkout
- Canonical web reference for Auth0 `sub` → SolvaPay customer linkage
- README: [examples/typescript/nextjs-auth0/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/nextjs-auth0/README.md)

### checkout-demo

- Embedded checkout with React components
- Uses Supabase auth and purchase gating
- README: [examples/typescript/checkout-demo/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/checkout-demo/README.md)

### hosted-checkout-demo

- Hosted checkout and hosted customer portal
- Lower PCI complexity than embedded checkout
- README: [examples/typescript/hosted-checkout-demo/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/hosted-checkout-demo/README.md)

### shadcn-checkout

- Next.js App Router on port 3012, checkout composed from `@solvapay/react/primitives` (`PlanSelector`, `PaymentForm`, `AmountPicker`, `TopupForm`)
- Every primitive is mapped onto a shadcn/ui component with `asChild`, so SolvaPay owns behavior and shadcn owns the visual surface
- Four canonical files to copy into your own project: `app/providers.tsx`, `lib/solvapay.ts`, `app/api/solvapay/[...solvapay]/route.ts`, `app/checkout/page.tsx`
- Runs keyless — `lib/solvapay.ts` falls back to `createStubSolvaPay()` unless `SOLVAPAY_SECRET_KEY` is set
- README: [examples/typescript/shadcn-checkout/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/shadcn-checkout/README.md)

### tailwind-checkout

- Same four-file structure as `shadcn-checkout` on port 3011, styled with plain Tailwind v4 utilities and `data-[state=…]` variants
- No `@solvapay/react/styles.css` import — every pixel is styled in userspace
- README: [examples/typescript/tailwind-checkout/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/tailwind-checkout/README.md)

### chat-checkout-demo

- Gemini-powered chat gated with `payable.gate(req, { ctx })` — the decision-shaped paywall primitive for streaming responses
- Subscription, one-time, and top-up flows in one chrome; anonymous customers via `getOrCreateAnonymousCustomerRef`
- One source tree, two runtimes: Vite middleware for `pnpm dev`, a Cloudflare Worker for deploy
- README: [examples/typescript/chat-checkout-demo/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/chat-checkout-demo/README.md)

### supabase-edge

- Fetch-native backend for Supabase Edge Functions using `@solvapay/server/fetch`
- One two-line file per handler; `solvapayWebhook` factory for webhooks
- README: [examples/typescript/supabase-edge/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/supabase-edge/README.md)

### mcp-time-app

- MCP app UI resource + protected tools
- Demonstrates `createSolvaPayMcpServer` and `registerPayable` with OAuth context
- README: [examples/typescript/mcp-time-app/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/mcp-time-app/README.md)

### mcp-oauth-bridge

- Local discovery metadata for non-hosted MCP origin
- OAuth + dynamic client registration bridge pattern
- README: [examples/typescript/mcp-oauth-bridge/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/mcp-oauth-bridge/README.md)

### mcp-checkout-app

- Full 5-intent MCP App (plans, checkout, top-up, usage, paywall)
- Hybrid checkout: embedded Stripe Elements via `<PaymentForm>` on compliant hosts (`basic-host`, ChatGPT); auto-falls back to hosted SolvaPay checkout on hosts that ignore `_meta.ui.csp` (Claude)
- Ships with `createMcpAppAdapter` wired to `SolvaPayProvider` and a paywalled demo toolbox
- README: [examples/typescript/mcp-checkout-app/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/mcp-checkout-app/README.md)

### cloudflare-workers-mcp

- Single `fetch` handler built with `createSolvaPayMcpFetch` from `@solvapay/mcp/fetch` — OAuth discovery, bridge routes, tool calls, and the widget iframe in one worker
- Ships a seeded stock-predictor demo toolbox (`predict_price_chart`, `predict_direction`) to exercise the paywall end-to-end
- README: [examples/typescript/cloudflare-workers-mcp/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/cloudflare-workers-mcp/README.md)

### supabase-edge-mcp

- Same toolbox as `cloudflare-workers-mcp`, deployed as a single Supabase Edge Function
- Uses `Deno.serve(createSolvaPayMcpFetch(…))` from `@solvapay/mcp/fetch`
- Pair with `supabase-edge-mcp-proxy` if you need a custom domain in front of Supabase's `/functions/v1/…` URL shape (required for RFC 9728 `.well-known/oauth-protected-resource` discovery)
- README: [examples/typescript/supabase-edge-mcp/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/supabase-edge-mcp/README.md)

### supabase-edge-mcp-proxy

- Cloudflare Worker that remaps `https://your-subdomain/*` → `https://<proj>.supabase.co/functions/v1/mcp/*`
- Fixes OAuth Protected Resource Metadata discovery for MCP Inspector and ChatGPT connectors
- README: [examples/typescript/supabase-edge-mcp-proxy/README.md](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/supabase-edge-mcp-proxy/README.md)
