## Prerequisites

- Node.js 20 or later (`@solvapay/server` and `@solvapay/mcp` require it)
  - On Node.js 20, update npm to version 11 first (`npm install -g npm@11`), or use Node.js 22. Node 20's bundled npm 10 can't install Vite 8 projects on Linux, including the MCP template from `npm create solvapay@latest -- --type mcp`.
- npm, yarn, or pnpm

## 1) Run the CLI setup

From your project root:

```bash
npx solvapay@latest init
```

This command authenticates you, writes `SOLVAPAY_SECRET_KEY`, installs core packages, and
prints a starter snippet.

See [CLI setup](./cli) for full details.

## 2) Protect your first endpoint (Express)

```typescript
import express from 'express'
import { createSolvaPay } from '@solvapay/server'

const app = express()
app.use(express.json())

const solvaPay = createSolvaPay()
const payable = solvaPay.payable({
  product: 'prd_YOUR_PRODUCT',
})

app.post(
  '/tasks',
  payable.http(async req => {
    return {
      success: true,
      task: {
        title: req.body.title,
      },
    }
  }),
)
```

Test it:

```bash
curl -X POST http://localhost:3000/tasks \
  -H "Content-Type: application/json" \
  -H "x-customer-ref: user_123" \
  -d '{"title":"My first task"}'
```
