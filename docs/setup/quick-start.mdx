## Prerequisites

- Node.js 22 or later (`@solvapay/server` and `@solvapay/mcp` require it)
- npm, yarn, or pnpm

## 1) Run the CLI setup

From your project root:

```bash
npx solvapay@latest init
```

This command authenticates you, writes `SOLVAPAY_SECRET_KEY`, installs core packages, and
prints a starter snippet.

See [CLI setup](./cli) for full details.

## 2) Protect your first endpoint (Express)

```typescript
import express from 'express'
import { createSolvaPay } from '@solvapay/server'

const app = express()
app.use(express.json())

const solvaPay = createSolvaPay()
const payable = solvaPay.payable({
  product: 'prd_YOUR_PRODUCT',
})

app.post(
  '/tasks',
  payable.http(
    async req => {
      return {
        success: true,
        task: {
          title: req.body.title,
        },
      }
    },
    {
      // Who is calling, from your own auth. This quick start trusts a header so
      // you can try it with curl; return the user from your session, API key or
      // verified token instead.
      getCustomerRef: req => req.header('x-user-id') ?? '',
    },
  ),
)
```

Test it:

```bash
curl -X POST http://localhost:3000/tasks \
  -H "Content-Type: application/json" \
  -H "x-user-id: user_123" \
  -d '{"title":"My first task"}'
```

Without `getCustomerRef`, `payable.http` takes the customer only from a verified bearer token (`SOLVAPAY_JWT_SECRET`, `SOLVAPAY_JWKS_URL` or Supabase), or from an `x-customer-ref` header behind a gateway you trust (`SOLVAPAY_AUTH_TRUST_GATEWAY=true`). An `x-customer-ref` sent without that opt-in gets a 401, and a request with neither is anonymous.
