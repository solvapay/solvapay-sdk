> Recommended: use [CLI setup](./cli) — `npx solvapay init` for existing projects, or
> `npm create solvapay -- --type mcp | next-auth0` to scaffold a new one.  
> This page covers the manual setup path.

## Prerequisites

- Node.js 18.17 or higher — 20 or higher for `@solvapay/mcp` and `@solvapay/mcp-core`
- npm, yarn, or pnpm
- TypeScript 5.0+ (recommended)

## Install packages by use case

### Server-side protection

```bash
npm install @solvapay/server
```

### React checkout components

```bash
npm install @solvapay/react
```

### Next.js integration

```bash
npm install @solvapay/next
```

### Auth adapters

```bash
npm install @solvapay/auth
```

### Supabase Edge Functions

For Deno-based Supabase Edge Functions, no npm install is needed. Use an import map in `supabase/functions/deno.json` instead. See the [Supabase Edge Functions guide](/sdks/typescript/guides/supabase-edge) for setup.

### Supabase adapter for React

```bash
npm install @solvapay/react-supabase @supabase/supabase-js
```

### Core types only

```bash
npm install @solvapay/core
```

## Environment variables

Required for production:

```bash
SOLVAPAY_SECRET_KEY=sk_live_...
```

Optional:

```bash
SOLVAPAY_API_BASE_URL=https://api.solvapay.com
```

## Running without a secret key

`createSolvaPay()` requires a secret key — it throws `Missing apiKey` when neither
`config.apiKey` nor `SOLVAPAY_SECRET_KEY` is set. There is no automatic stub mode.

To run keyless for local development or tests, inject your own `apiClient`. Anything
implementing `SolvaPayClient` works; the repo ships a demo stub at
[`examples/typescript/shared/stub-api-client.ts`](https://github.com/solvapay/solvapay-sdk/blob/main/examples/typescript/shared/stub-api-client.ts).

```typescript
import { createSolvaPay } from '@solvapay/server'
import { createStubClient } from '../shared/stub-api-client'

const solvaPay = createSolvaPay({
  apiClient: createStubClient({ freeTierLimit: 5 }),
})
```

When `apiClient` is supplied, the SDK never constructs a real API client, so no key is
read. See [`examples/typescript/express-basic`](https://github.com/solvapay/solvapay-sdk/tree/main/examples/typescript/express-basic)
for a complete keyless example.
