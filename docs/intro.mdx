## What is SolvaPay SDK?

SolvaPay SDK helps you monetize APIs, AI apps, and MCP servers with a type-safe API.
You can protect endpoints with paywalls, check purchases, and run checkout flows from one SDK.

## Core capability

Protect routes and tools with one pattern:

```typescript
// Express.js
app.post('/tasks', payable.http(createTask))

// Next.js App Router
export const POST = payable.next(createTask)

// MCP Server — register paid tools on the batteries-included factory
const server = createSolvaPayMcpServer({
  solvaPay,
  productRef: 'prd_myapi',
  resourceUri: 'ui://my-app/mcp-app.html',
  htmlPath: './mcp-app.html',
  publicBaseUrl: 'https://my-mcp.example.com',
  additionalTools: ({ registerPayable }) => {
    registerPayable('create_task', {
      schema: { title: z.string() },
      handler: async ({ title }, ctx) => ctx.respond(await createTask(title)),
    })
  },
})
```

## Headless React components

Build beautiful payment flows with headless React components that work with any design system:

```tsx
import { PaymentForm, usePurchase } from '@solvapay/react'

function CheckoutPage() {
  const { hasPaidPurchase } = usePurchase()

  return (
    <PaymentForm
      planRef="pln_premium"
      productRef="prd_myapi"
      onSuccess={() => router.push('/dashboard')}
    />
  )
}
```

## Why teams use it

- Single server API for Node and Edge runtimes
- CLI setup with `npx solvapay init`
- Headless React components for checkout flows
- Built-in auth adapters and Next.js helpers

## Packages

Each package is versioned independently — follow the npm link for the current release.

| Package                                                                              | Purpose                                                                                                                                                        |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`@solvapay/core`](https://www.npmjs.com/package/@solvapay/core)                     | Types, schemas, and shared utilities                                                                                                                           |
| [`@solvapay/server`](https://www.npmjs.com/package/@solvapay/server)                 | Paywall protection, purchase checks, and webhooks. `@solvapay/server/fetch` ships fetch-native handlers for Edge / Deno / Cloudflare / Supabase Edge Functions |
| [`@solvapay/react`](https://www.npmjs.com/package/@solvapay/react)                   | Provider, hooks, checkout, and account components. `@solvapay/react/mcp` adds the MCP App surface                                                              |
| [`@solvapay/react-supabase`](https://www.npmjs.com/package/@solvapay/react-supabase) | Supabase adapter for React                                                                                                                                     |
| [`@solvapay/auth`](https://www.npmjs.com/package/@solvapay/auth)                     | Auth adapters and server helpers                                                                                                                               |
| [`@solvapay/next`](https://www.npmjs.com/package/@solvapay/next)                     | Next.js route helpers                                                                                                                                          |
| [`@solvapay/mcp`](https://www.npmjs.com/package/@solvapay/mcp)                       | MCP server adapter for `@modelcontextprotocol/server`; `@solvapay/mcp/fetch` and `@solvapay/mcp/express` subpaths bridge OAuth by runtime                      |
| [`@solvapay/mcp-core`](https://www.npmjs.com/package/@solvapay/mcp-core)             | Framework-neutral MCP contracts — tool names, descriptors, bootstrap payloads                                                                                  |
| [`solvapay`](https://www.npmjs.com/package/solvapay)                                 | CLI — `npx solvapay init` adds SolvaPay to an existing project                                                                                                 |
| [`create-solvapay`](https://www.npmjs.com/package/create-solvapay)                   | Scaffolder — `npm create solvapay -- --type mcp \| next-auth0`                                                                                                 |

`@solvapay/mcp` and `@solvapay/mcp-core` require Node 20+; the rest require Node 18.17+.
