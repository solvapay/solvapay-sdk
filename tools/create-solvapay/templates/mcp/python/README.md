# __SERVER_NAME__

Paid MCP server generated by `create-solvapay --type mcp --language python`.

## Run

```bash
uv sync
# or: pip install -e .
cp .env.example .env   # then run `npx solvapay init` if you skipped it
uv run python main.py --mode http
```

The MCP endpoint is `/mcp` on `MCP_HOST`/`MCP_PORT` (default `127.0.0.1:3030`).

```bash
./scripts/http.sh
./scripts/tunnel.sh    # requires ngrok
```

Replace the placeholder `__TOOL_NAME__` tool in `tools.py` before going live.
