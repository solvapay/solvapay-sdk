# **SERVER_NAME**

Paid MCP server generated by `create-solvapay --type mcp --language rust`.

## Run

```bash
cargo fetch
cp .env.example .env   # then run `npx solvapay init` if you skipped it
cargo run -- --mode http
```

The MCP endpoint is `/mcp` on port 3030 by default.

```bash
./scripts/http.sh
./scripts/tunnel.sh
```

Replace the placeholder `__TOOL_NAME__` tool in `src/main.rs` before going live.
