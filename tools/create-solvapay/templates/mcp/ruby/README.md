Paid MCP server generated by `create-solvapay --type mcp --language ruby`.

## Run

```bash
bundle install
cp .env.example .env   # then run `npx solvapay init` if you skipped it
bundle exec ruby main.rb --mode http
```

The MCP endpoint is `/mcp` on port 3030 by default.
