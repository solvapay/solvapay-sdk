# **PROJECT_NAME**

A paid MCP server in Python, built with the [SolvaPay Python SDK](https://docs.solvapay.com/sdks/python/intro) and generated by `npm create solvapay -- --type mcp --language python`.

Customers sign in with SolvaPay over OAuth. Each call to a paid tool is checked against the customer's plan before your code runs; without a plan they get a paywall message that names the `account` tool and a checkout link.

## Layout

```
__PROJECT_NAME__/
├── server.py          # builds the server, loads .env, runs uvicorn
├── tools.py           # your tools: one paid, one free with a cap
├── tests/test_tools.py
├── pyproject.toml     # solvapay[mcp] pinned exactly; uv.lock holds the rest
├── .env.example       # the settings the server reads
├── Dockerfile         # for any container host
└── .github/dependabot.yml
```

## Prerequisites

- [uv](https://docs.astral.sh/uv/) (it installs Python 3.10+ for you).
- A SolvaPay product (`prd_…`) with at least one plan. `npx solvapay init` signs you in and writes `SOLVAPAY_SECRET_KEY` and `SOLVAPAY_PRODUCT_REF` to `.env`.

## Run locally

```bash
uv run python server.py          # http://localhost:8080/mcp
uv run pytest
```

MCP clients such as Claude and ChatGPT need a public HTTPS URL. Start a tunnel, put its URL in `.env` as `PUBLIC_BASE_URL`, and restart the server:

```bash
ngrok http 8080
```

`PUBLIC_BASE_URL` must be the URL clients use. It is the OAuth issuer the client sees, and the server's host check allows only it and localhost.

Check the server:

```bash
npx solvapay verify http://localhost:8080/mcp
```

## Add your tools

Edit `tools.py`. A handler is an async function: its parameters, except `ctx: ResponseContext`, become the tool's input schema, and it returns `ctx.respond(data)`. Register it with `mcp.register_payable(...)` for a paid tool or `mcp.register_free(..., limit=FreeLimit(...))` for a free one with a cap. See the [Paid MCP server guide](https://docs.solvapay.com/sdks/python/guides/mcp).

Don't register your own `account` or `activate_plan` tools: the SDK adds them, and the paywall points customers at them.

## Deploy

Build the container and run it anywhere that gives it an HTTPS URL. Set `SOLVAPAY_SECRET_KEY`, `SOLVAPAY_PRODUCT_REF` and `PUBLIC_BASE_URL` in the host's environment (secrets in its secret store); `.env` is not copied into the image.

Google Cloud Run:

```bash
gcloud run deploy __PROJECT_NAME__ --source . --region europe-west1 --allow-unauthenticated \
  --set-env-vars SOLVAPAY_PRODUCT_REF=prd_...,PUBLIC_BASE_URL=https://<service url> \
  --set-secrets SOLVAPAY_SECRET_KEY=solvapay-secret-key:latest
```

Deploy once to learn the service URL, then set `PUBLIC_BASE_URL` to it and deploy again. Then run `npx solvapay verify https://<service url>/mcp`.

## Keep the SDK current

```bash
npx solvapay doctor    # checks the key, the product, and that solvapay is the newest release
```

Dependabot opens a pull request when a new `solvapay` release is out.
