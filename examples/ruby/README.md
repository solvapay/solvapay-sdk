# SolvaPay Ruby examples

Runnable examples for the Ruby gem (`solvapay` on RubyGems).

| Example                                           | Description                                                                        |
| ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [get_merchant](./get_merchant)                    | Fetch the merchant profile via `SolvaPay::Client#get_merchant`                     |
| [paid_mcp](./paid_mcp)                            | Paywalled MCP echo (`solvapay/mcp`) against a mock backend                         |
| [bitcoin_analytics_mcp](./bitcoin_analytics_mcp)  | Paywalled MCP tools composing Bitcoin halving, mempool.space, and btcnode data. Ngrok via `pnpm mcp:bitcoin-analytics:tunnel` |
