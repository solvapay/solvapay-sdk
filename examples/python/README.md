# SolvaPay Python examples

Runnable examples for the Python binding (`solvapay` on PyPI).

| Example                                    | Description                                                                                                               |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| [get-merchant](./get-merchant)             | Fetch the merchant profile via `SolvaPayClient.get_merchant_blocking`                                                     |
| [paid-mcp](./paid-mcp)                     | Paywalled MCP tool (`solvapay-mcp`) against a mock backend                                                                |
| [stock-research-mcp](./stock-research-mcp) | Paywalled MCP tools composing a ranked watchlist with SEC company data. HTTP + ngrok via `pnpm mcp:stock-research:tunnel` |
